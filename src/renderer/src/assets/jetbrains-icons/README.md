# JetBrains file icons

Vendored from https://github.com/peakoss/vscode-jetbrains-icon-theme
at commit `f7cc2cfb53390322fd8b9966494e80f73d71ff84` (version 2.40.0).

The unmodified `assets/2023/theme-light.json`, `theme-dark.json` and all SVGs
referenced by their icon definitions are bundled locally. No extension runtime
or network access is required, including for SSH and folder workspaces.

See `LICENSE.md` for the upstream MIT license and the Apache 2.0 terms for
the Elixir icons. Keep the license with these assets when updating them.
